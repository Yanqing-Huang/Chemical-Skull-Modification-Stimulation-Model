# TrackA2 — 纯机理模型路线（本轮新建）

**调机理、把频率等等各种都算进去、把所有条件都考虑进去。**

```
Archie 电导     sigma = sigma_floor + c*phi^m
脱钙孔隙率演化   phi(t,d) ~ (d/D0)^beta * (t/T0)^p
界面极化 / CPE   G_pol(f) ~ (f/F0)^(-s)，与离子通路并联
总导纳           Y(f,t,d) = G_ion(t,d) + G_pol(f)
R_Z             = Y(0)/Y(t) = 1/(1+delta_eff)
delta_eff       = a0*(d/D0)^beta*(t/T0)^p*(f/F0)^(-s)
```

- 4 个参数全是物理量：`a0` 改性幅度、`beta` 剂量指数、`p` 脱钙时间指数、`s` 界面极化频散指数。
  `D0=0.10 mol/L, T0=100 min, F0=100 Hz`。
- **频率 f 内生进机理方程**，可解释实测「同一时间高频 R_Z 偏高」；t=0 天然=1；值域 (0,1]。
- **零经验回归系数**；单一组参数覆盖 4 剂量 x 4 频率 x 6 时间 = 96 条件节点，
  跨 C2/C3/C4 零重拟合迁移 R2 仍 >0.91（见 `../four_conditions/THREE_ROUTES_CONCLUSION.md` 第 3 节）。
- `model.py` **完全自包含**，不读任何外部数据文件。

诚实边界：物理量由实测标定，不是纯先验推导；`s` 是等效频散指数不是被辨识的 CPE 指数；
delta_eff 单调，无法表达尿素 t=105 回升。详见 `../docs/MECHANISM_PRINCIPLE.md`。

## 本模型涉及的机理原理（核心）

> 完整推导、符号量纲、参数可辨识性与数值对照见
> [`../docs/MECHANISM_PRINCIPLE.md`](../docs/MECHANISM_PRINCIPLE.md) 第 2–6、8 节；附录 A 为符号与量纲总表。

| 原理 | 公式 / 结论 | 总纲章节 |
|---|---|---|
| EDTA 脱钙化学 | 螯合 `Ca2+` → 孔隙率 `phi(t,d)` 上升 | 1 |
| Archie 电导 | `sigma = sigma_floor + c·phi^m`（残余项保证 `Z0` 有限） | 2 |
| 串联积分 / 归一化 | `R = Σ dx/(sigma·A_cell)`、`R_Z=Z/Z0`、`t=0≡1`；旧准静态机理三个结构性缺口 | 3 |
| 界面极化 / CPE 并联导纳 | `Y = G_ion(t,d) + G_pol(f)`；高频旁路主导 → `R_Z` 系统性偏高 | 4 |
| `delta_eff` 逐步代数推导 | `R_Z = Y(0)/Y(t) = 1/(1+delta_eff)`，`delta_eff = G0·delta/(G0+G_pol)`；旁路主导极限 → `f^(-s)` | 5.1 |
| 4 个物理量 + 3 个参考标度 | `a0 / beta / p / s`；`D0=0.10 M, T0=100 min, F0=100 Hz` | 5.2–5.3 |
| 数学性质 | 基线天然=1、值域 `(0,1]`、对 `t`/`d` 单调降、对 `f` 单调升 | 5.4 |
| 参数可辨识性 | `G0` 与 `rho` 尺度冗余（同时放大不改变 `R_Z`）→ 6→5→4 参数 → 全部落在边界内 | 6 |

> **关键澄清（总纲 5.1）**：严格链条是「CPE 旁路导纳随 `f` **上升** → 分母 `(G0+G_pol)` 变大 →
> `delta_eff` 被稀释 → `delta_eff ∝ f^(-s)`」；早期 121 行概览把 `G_pol(f) ~ (f/F0)^(-s)`
> 直接写成 CPE 频散，那是对 `delta_eff` 频率因子的**等效简写**，本轮已补全推导并说明
> `s` 是 CPE 指数在旁路主导近似下的等效值（非被辨识，E9）。
