## 「拟合效果最好的是哪一种」

**按唯一验收口径 `LORO`（逐鼠独立验证）：全局 TrackA3「机理驱动经验」最好**，四条件 LORO R² =
0.5201 / 0.7326 / 0.6408 / 0.7684，五模型全部第一；A2 次之，A1 系列最弱。
A3 只有 6 个参数，机理骨架定形状 + 两个受约束保形校准，`η=1, ε=0` 退化为 A2。

若只看样本内 `full`（群体均值层 in-sample，**仅参考、不作验收**）：分段 `SEG_A1` / `SEG_A3`
的 C1 full R² 0.9573 / 0.9538 高于全局 A3 的 0.9205，但那是样本内 + 条件收窄 + 自由度 6→11/13
抬高的，其 LORO 反而显著变差（ΔR² −0.0239 / −0.0258，95%CI 全在 0 左侧），**不可作为验收模型**。
分段里唯一没退步的是 `ADJ_A3`（C1 LORO 0.5226，ΔR²=+0.0025，CI 跨 0），只能表述为**不劣于**全局 A3。

TrackB 预测区间而非点值，成绩单是 coverage 0.908 / 0.913 / 0.946 / 0.978，不与 TrackA 横比。
