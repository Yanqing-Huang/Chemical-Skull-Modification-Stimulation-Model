## 1. 评价标准总表（逐条定义）

优先级图例：**验收口径** = 唯一可作结论的独立验证；**参考** = 辅助判读；
**不作数** = 只描述样本内表现，不能用于模型取舍；**铁律** = 硬性口径约束，违反即结论无效。

### 1.1 A 类 · 验证层级与数据切分（口径根基）

| 编号 | 标准 | 定义 / 公式 | 适用 | 优先级 | 判定规则 / 口径出处 |
|---|---|---|---|---|---|
| A1 | full（样本内）R² / RMSE / MAE / bias | 在拟合用的同一批条件均值节点上计算，R² = 1 − SSE/SST | TrackA | **不作数** | 只描述拟合程度；自由度越多越高，不能用来排名模型 |
| A2 | LOCO（留一条件） | 留一个 (剂量×频率×时间) 条件、其余条件拟合后外推；48 条件共享同一鼠群 | TrackA | 参考 | **群体均值层**，不检验大鼠级泛化；曾用「LOO」误称，实为 LOCO |
| A3 | **LORO（留一大鼠）** | 每次留一整只大鼠的全部节点，其余鼠拟合后外推；按鼠聚合预测再算 R² | TrackA | **验收口径** | 「不能用群体均值混淆个体验证」——用户既定；所有取舍以 LORO 为准 |
| A4 | 逐鼠 LORO 均值 | 对每只被留出的鼠单独算 R² 再取均值（`loro_per_rat_mean_r2`） | TrackA | 参考 | 反映个体间波动；方差大、个别鼠为负，仅作参考 |
| A5 | LORO 折数 | 被留出鼠的数量；C1/C2 = 24 折，C3/C4 = 12 折（被试间设计） | TrackA | 参考 | 折数不同 → 四条件 R² 不可横比（见 E1） |
| A6 | 评价集规模 | 条件节点 96 / 48 / 48 / 24；鼠级点 576 / 288 / 288 / 144；鼠数 24/24/12/12 | TrackA / TrackB | 参考 | 节点数不同，指标不具可比性 |
| A7 | 数据版本 gate | Excel SHA 冻结、三层核验（单位行 / +1 行偏移 / 2016 行逐格一致） | 全部 | **铁律** | 版本未核验不得进入拟合；源文件不改动 |
| A8 | 不利样本保留 | WT17 / WT9 / WT8 等低覆盖样本一律保留，14 处转录异常标记未决 | 全部 | **铁律** | 不得为抬高指标删样本 |

### 1.2 B 类 · TrackA 点预测指标

| 编号 | 标准 | 定义 / 公式 | 适用 | 判定规则 |
|---|---|---|---|---|
| B1 | R² | 1 − SSE/SST，越大越好，可为负（负 = 不如均值基线） | full / LOCO / LORO 三个层级分别报告 | LORO 层为验收口径 |
| B2 | RMSE | sqrt(mean((y−ŷ)²))，越小越好，与 R² 互补 | full / LOCO / LORO | 辅助误差量级 |
| B3 | MAE | mean(|y−ŷ|)，对离群点比 RMSE 稳健 | full | 参考 |
| B4 | bias | mean(ŷ−y)，检验系统性高估/低估 | full | 参考；本项目各模型接近 0 |
| B5 | AIC | n·ln(SSE/n)+2k（高斯误差，忽略与模型无关常数）；实现见 `run_three_routes.py`，**越小越好** | full | **已对参数个数 k 施加惩罚**；但未做多重比较校正（E6） |
| B6 | k 参数个数 | 自由参数数目（5 / 4 / 3 / 4 / 6） | 全部 | 越少越利于外推；须与 B5 同看 |
| B7 | 基线 t=0 外推 | 按物理定义 R_Z(t=0)≡1；检查模型未经锚定的 t=0 输出 | 全部 | **铁律**；A1.2 偏离 1（0.898–1.305）需人为锚定 |
| B8 | 参数可辨识性 | 检查参数是否顶到优化边界、是否存在互相补偿 | 全部 | 顶边界/补偿 = 不可辨识，应弃用 |
| B9 | 物理可解释性 / 机理含量 | 参数是否有物理量纲与含义；机理含量 无/低/中/100%/骨架100% | 全部 | 定性；与 B6、B11 同看 |
| B10 | 去尿素稳健性 | 剔除 t=105 尿素点后重算 LORO，检验排名是否翻转 | 全部 | **本轮未重算**；历史结论见第 4 节脚注 |
| B11 | 跨条件零重拟合迁移 | 用 C1 拟合的一套参数、不重拟合，直接评估 C2/C3/C4 | A2（结构性优势） | R² 保持 >0.91 视为「覆盖所有条件」 |
| B12 | 自包含性 | model.py 是否读外部数据文件 | 全部 | A2/A3/A1.1 自包含；A1.2/A1.3 需机理先验 CSV |

### 1.3 C 类 · TrackB 区间指标（不报 R² / RMSE）

| 编号 | 标准 | 定义 / 公式 | 适用 | 判定规则 / 口径出处 |
|---|---|---|---|---|
| C1 | coverage 覆盖率 | 落入校准区间的实测点占比，目标 **0.90** | 四条件 | 达标线；但高覆盖率可能靠宽区间买来，须与 C2 同看 |
| C2 | mean width 平均宽度 | 区间上界−下界的均值 | 四条件 | 越窄越好（同等覆盖率下） |
| C3 | median width 中位宽度 | 区间宽度的中位数 | 四条件 | 不受极端宽区间影响 |
| C4 | max width 最大宽度 | 区间宽度的最大值 | 四条件 | 高频段显著更宽 |
| C5 | Winkler (α_mis=0.10) | 区间评分：宽度 + (2/α)·越界距离，越小越好 | 四条件 | 综合覆盖率与宽度的唯一推荐指标 |
| C6 | 宽度构成 padding 占比 | padding 双侧贡献 / 总宽度；B1 诊断低频 196 点 = **97.09%**，基础 LHS 区间仅 **3.00%** | TrackB | **宽区间根因是 conformal padding，不是 LHS 参数不确定性** |
| C7 | 逐点 vs 联合覆盖 | 逐点覆盖率 ≠ 整条时间曲线同时落入区间的概率 | TrackB | **铁律**；不可把逐点 0.913 说成整曲线 91.3% |
| C8 | 无区间时段 | 基线 t=0 与尿素 t=105 无校准区间 | TrackB | 绘图须标注灰虚线，不可伪造区间 |
| C9 | padding 公式 | p_(fold,f) = tolerance_f × q_f，q_f = Quantile_0.90(内层 cross-fit 分数)；lower=clip(q05−p,0,1)，upper=clip(q95+p,0,1) | TrackB | 与上游公式一致，P0 审计复现误差 1.39e−16 |

> **TrackB 不报 R² / RMSE**（用户既定铁律）：区间模型的优劣用 C1–C5 判定，
> 点预测误差指标不适用于区间任务，也不与 TrackA 的 R² 横向比较。

### 1.5 E 类 · 判定铁律（元标准，违反即结论无效）

| 编号 | 铁律 | 理由 | 判定 |
|---|---|---|---|
| E1 | **四条件 R² 不可横比** | 评价集节点 96/48/48/24、折数 24/24/12/12 各不相同 | 「0.627→0.782→0.894 递增」是评价集收窄，不是模型变好 |
| E2 | **条件越窄 ≠ 模型越好** | 去高频、去两个剂量、两高浓度曲线近似重合 | C4 的漂亮数字来自评价范围收窄 + 12 鼠小样本 |
| E3 | **拟合变好 ≠ 机理更正确** | 条件收窄、加自由度、补协变量都会抬高 R² | A1 系列是经验校正，不是机理改进；补 ln(f) 等于承认机理缺频散项 |
| E4 | **指标最优 ≠ 可用模型** | 样本内第一不代表可外推、可解释 | A1.1 拉伸指数样本内最高，但 5 参数无物理意义、脱离机理链路 |
| E5 | **噪声级差异不声称提升** | LORO 差 0.002–0.007 远小于逐鼠波动 | 不得写成「性能提升」或「性能下降」 |
| E6 | AIC 罚参数但未做多重比较校正 | 小样本 96/48/24 节点、多模型比较存在选择偏差 | AIC 仅作辅助，不作唯一判据 |
| E7 | 逐鼠 LORO 方差大 | 个别鼠 R² 为负（WT17 / WT2 历史） | 逐鼠均值仅作参考 |
| E8 | 尿素 t=105 回升无法表达 | 所有单调模型（含 A2 纯机理）皆然 | 黄色区标注；需在机理层补界面重构 / 再封闭项 |
| E9 | s 不是被辨识的 CPE 指数 | 仅 4 个频率点，幂律 / 加性 ln(f) / 交互形式统计不可分 | 需独立宽频 EIS 介电谱实验 |
| E10 | 三条路线不构成机理被证实 | 物理量由实测标定，不是第一性原理推导 | 「机理驱动」指结构来自机理，不指全部参数可溯源 |

## 7. 验收流程：怎么用这些标准选模型

1. **先看口径**：数据版本已 gate（A7）、不利样本保留（A8）、四条件不横比（E1/E2）。
2. **只看 LORO**（A3）作结论；full / LOCO 仅读数，不排名（A1/A2）。
3. **再查硬门槛**：基线 t=0 是否天然=1（B7）、参数是否可辨识（B8）、是否报了不该报的指标（TrackB 不报 R²/RMSE）。
4. **同等 LORO 下**用 B5 AIC（罚参数）、B6 k、B9 物理可解释性、B10 稳健性、B11 迁移能力破同分。
5. **噪声级差异不判胜负**（E5）；**指标最优 ≠ 可用模型**（E4）；**拟合变好 ≠ 机理更正确**（E3/E10）。
6. **TrackB 单独走 C 类**：coverage / width / Winkler 一起看，并始终说明 padding 占比（C6）。

按此流程：综合最平衡 → **TrackA3**；最纯机理 / 最少参数 / 一套参数覆盖全条件 → **TrackA2**；
样本内数字最大 → A1.1（不作交付模型）；区间任务 → **TrackB**（不与点预测横比）。
