# 「机理 + 经验」下的机理原理

> 回答：三条 TrackA 路线里哪些是机理、哪些是经验、两者怎么接、机理上还缺什么。
> 对应 `TrackA1/`（纯经验）、`TrackA2/`（纯机理）、`TrackA3/`（机理驱动经验）与 `TrackB/`。

## 1. 机理底座（三条路线共享的物理事实）

EDTA 螯合颅骨羟基磷灰石中的 Ca，使孔隙率 phi 上升，离子电导上升，阻抗下降：

```
sigma = sigma_floor + c * phi^m                 (Archie 型局部电导率)
R     = sum_i dx_i / (sigma_i * A_cell)         (沿厚度串联积分，旧准静态纯电阻网络)
R_Z   = Z(t) / Z(0)                            (归一化阻抗比，t=0 按定义等于 1)
```

旧机理（`data/mechanism_timeseries_quantiles.csv` 的 whole_resistance_ratio）有三个结构性缺口：

| 缺口 | 证据 | 后果 |
|---|---|---|
| **频率无关** | 旧 `R_Z_raw` 与 f 完全无关（只有剂量 x 时间一条曲线族）；实测 100/120/1000/10000 Hz 明显分层 | 机理先验无法表达频率维度，是最大误差源 |
| **脱钙动力学幅度太小/太慢** | 旧 `raw` 只降到 0.794-0.883（改性量 0.12-0.21）；实测降到 0.12-0.92 | 需要放大或补时间维度 |
| **95 min 后截断 + 尿素回升** | 先验在 95 min 取末值平台；实测 t=105（乙醇+尿素）回升 | 所有单调模型无法表达 |

## 2. TrackA2 纯机理：把频率写进机理方程（本轮核心）

物理图像：真实颅骨不是纯电阻，而是「**离子通路 ∥ 界面极化 / CPE 电容旁路**」并联。

- 低频（100/120 Hz）：电流主要走细胞外液 / 孔隙的**离子通路**。脱钙使 phi 上升、sigma 上升，Z 显著下降。
- 高频（1000/10000 Hz）：电容耦合与界面极化旁路占主导，对 phi 变化不敏感，
  改性后 R_Z 更接近 1 —— 正好解释实测「同一时间下高频 R_Z 系统性偏高」。

设总导纳 `Y(f,t,d) = G_ion(t,d) + G_pol(f)`，阻抗 `Z = 1/Y`，则
`R_Z = Z(t)/Z(0) = Y(0)/Y(t) = 1/(1 + delta_eff)`，其中把
「孔隙率脱钙演化」与「界面极化 CPE 频散」写成可标定的物理量：

```
phi(t,d)   ~ (d/D0)^beta * (t/T0)^p            (脱钙量随剂量、时间幂律增长)
G_pol(f)   ~ (f/F0)^(-s)                       (CPE 频散：频率越高，改性量被稀释)
delta_eff  = a0 * (d/D0)^beta * (t/T0)^p * (f/F0)^(-s)
R_Z        = 1 / (1 + delta_eff)
```

四个参数全是物理量：**a0**（参考条件下改性幅度）、**beta**（剂量指数）、
**p**（脱钙动力学时间指数）、**s**（界面极化频散指数）；
`D0=0.10 mol/L, T0=100 min, F0=100 Hz` 为固定参考标度。

性质：
- **频率 f 内生进机理方程**（不再需要一个 `d*ln(f/100)` 的经验协变量）；
- **t=0 天然等于 1**，无需人为锚定；值域 (0,1]，无需 clip；
- **单一组参数覆盖所有条件**：4 剂量 x 4 频率 x 6 时间 = 96 节点，零经验回归系数；
- 4 参数全部落在拟合边界内部，可辨识（早期试过 `G_ion(0)` 与 `G_pol` 的尺度冗余参数化，
  a0 与 rho 会双双顶到上界，已弃用，改用归一化有效改性量）。

## 3. 经验层在三条路线里的位置

### TrackA1 纯经验（A1.1 / A1.2 / A1.3）

主体是数据驱动的曲线 / 回归拟合，参数无物理量纲：

- **A1.1 拉伸指数** `C+(1-C)exp(-(bt)^n)`：完全脱离机理链路，直接对时间拟合衰减曲线，
  `b` 里塞进剂量与频率的线性组合。
- **A1.2 A+** `a + b*R_Z_raw + c*t + d*ln(f/100)`：把旧机理先验 `raw` 当**一个查表特征**，
  再加 t 与 ln(f) 两个经验协变量；c、d 没有物理出处，t=0 外推偏离 1 需人为锚定。
- **A1.3 H1 混合** `1 - kappa*(f/100)^(-s)*(1-raw) - eps*t`：用机理改性量 `delta=1-raw` 作**形状骨架**，
  但 kappa/s/eps 仍是拟合系数。

> 诚实标注：按本轮归类，三者同属「TrackA1 纯经验路线」；严格按成分，
> **A1.1 是唯一完全脱离机理链路的纯经验模型**，A1.2 / A1.3 仍以机理先验输出作输入特征或形状骨架。

### TrackA3 机理驱动经验

机理定函数形状与全部约束（基线=1、单调、频率分层、剂量/时间幂律结构），
经验层只加 **2 个受约束的保形校准系数**：

```
R_mech = TrackA2 的纯机理预测（前 4 个物理参数，stagewise 固定）
R_Z    = 1 - eta*(1 - R_mech) - eps*(t/105)
```

- **eta** 缩放机理幅度（机理低估/高估改性幅度时的整体校准）；
- **eps** 补机理尚未覆盖的时间漂移；
- `eta=1, eps=0` 时严格退化为 A2 —— 三条路线里 A2 与 A3 是**嵌套**关系，
  经验层的边际贡献可以直接量化（四条件 LORO 提升 0.028-0.040）。

### TrackB 机理 ensemble + conformal 校准

机理 LHS ensemble 给 `sim_q05/q50/q95`，折 x 频率分层 conformal 校准给 padding：

```
p_(fold,f) = tolerance_f * q_f,  q_f = Quantile_0.90(内层 cross-fit 分数)
calibrated_lower = clip(sim_q05 - p, 0, 1)
calibrated_upper = clip(sim_q95 + p, 0, 1)
```

B1 诊断：**最终宽度约 97% 来自 padding，基础 LHS 参数不确定仅约 3%** ——
「区间过宽」的根因不是参数采样范围不足，盲目扩大 LHS 采样没有用。
TrackB 只报 coverage / width / Winkler，**不报 R2 / RMSE**。

## 4. 必须诚实说明的边界

- **物理量是被标定，不是被推导**：A2 的 a0/beta/p/s 由实测最小二乘标定，
  是「有物理量纲与物理含义的参数」，不等于从第一性原理算出；`s` 是等效频散指数，
  不是被独立辨识的 CPE 指数（仅 4 个频率点，幂律 / 加性 ln(f) / 交互形式统计上不可区分，
  需独立宽频 EIS 介电谱实验才能辨识）。
- **A2 仍不覆盖尿素段**：delta_eff 对时间单调，t=105 实测回升无法表达；机理上需要
  引入尿素导致的蛋白/孔道再封闭或界面重构项，本轮未做。
- **脱钙动力学是幂律等效**：`(t/T0)^p` 是扩散/反应控制过程的等效描述，
  不是被辨识的孔隙率演化方程；真正修复需用孔隙率 / 钙含量实测重标定 phi(t)。
- **拟合变好 != 模型变好**：条件收窄、新增自由度、补协变量都会抬高 R2；
  一律以 LORO 留一大鼠为验收口径，且四条件评价集不同不可横比。
- **A3 的经验系数仍是经验**：eta/eps 有明确校准含义但不是物理常数；
  「机理驱动」指结构来自机理，不指全部参数可溯源。

## 5. 一句话总括

> **机理层**回答「阻抗为什么降」（脱钙 -> 孔隙率 -> 电导率 -> 导纳上升）与
> 「频率为什么分层」（离子通路 ∥ 界面极化旁路）；
> **经验层**只负责标定机理尚未确定的幅度、动力学指数与个体误差。
> A1 是数据驱动的曲线/回归拟合，A2 把频率维度直接写回机理方程并做到零经验层，
> A3 用机理骨架加 2 个受约束校准系数在精度与可解释性之间取平衡。
> 三者都不构成「机理被证实」，只是「有物理动机的参数化」。
