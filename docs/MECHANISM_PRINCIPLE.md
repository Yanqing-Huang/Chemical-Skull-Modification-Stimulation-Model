## 1. 原理一：EDTA 脱钙化学（一切的物理起点）

- **无机相**：颅骨矿物质主要是碳酸替代型羟基磷灰石 `Ca10(PO4)6(OH)2`（Ca/P 约 1.67），
  以微晶形式填充在胶原基质中，晶间与骨小管/哈弗管构成含电解液的孔隙网络。
- **螯合反应**：EDTA（乙二胺四乙酸，完全去质子化为 `Y4-`）与 `Ca2+` 形成 1:1 可溶螯合物
  `Ca2+ + Y4- -> CaY2-`（log K 约 10.7，碱性条件），把 Ca 从晶格表面持续抽走并带走，
  反应不可逆地向右进行。
- **电学后果**：矿物溶解 → 微孔/微裂纹扩大、孔隙率 `phi` 上升 → 孔内离子液连通性上升 →
  有效电导率上升 → 阻抗下降。这就是 `R_Z = Z(t)/Z0 < 1` 的化学根源。
- **剂量依赖**：`d` 越高，螯合剂摩尔数与反应前沿推进越快 → `phi` 随 `d` 幂律增长（对应指数 `beta`）。
- **时间依赖**：由「Ca 从晶格溶出」与「EDTA 在孔内扩散」两步控制，早期快、后期趋缓；
  本项目用 `(t/T0)^p`（`p` 小于 1 的次线性）作为**等效描述**，不是被辨识的反应/扩散动力学方程。
- **实测阶段序列**：`baseline`(t=0) → `acetic_acid` → EDTA 四个剂量 → 改性时间点
  `[5, 20, 35, 65, 95]` min → `urea_10`(t=105)。共 4 剂量 × 4 频率 × 7 时间点（含基线）。
- **尿素段**：t=105 加入乙醇+尿素后实测 `R_Z` 回升，机理上可能对应蛋白/孔道再封闭或界面重构；
  当前所有单调机理（含 A2）均无法表达，见第 9 节。

## 2. 原理二：Archie 型有效电导率

多孔介质经典 **Archie 定律**：饱和岩体电导率 `sigma_b = sigma_w / F`，地层因子 `F = phi^(-m)`，
即 `sigma_b = sigma_w · phi^m`（`m` 为胶结/连通性指数，常见 1.3–2.5，反映孔道曲折度）。
本模型使用带残余项的推广式：

```
sigma = sigma_floor + c * phi^m
```

| 符号 | 含义 | 量纲 / 单位 | 为什么需要 |
|---|---|---|---|
| `sigma` | 局部有效电导率 | S/m | 决定该层电阻 |
| `sigma_floor` | 脱钙前基质 / 结合水 / 细胞质的残余电导 | S/m | 若纯 `sigma ∝ phi^m`，`phi→0` 时阻抗发散；实测基线 `Z0` 有限，故必须有残余项 |
| `c` | 孔隙液电导率标度 | S/m | 把孔隙率折算成电导的系数 |
| `m` | 胶结指数（孔道曲折度） | 无量纲 | Archie 定律的经验指数 |
| `phi` | 孔隙率 | 无量纲体积分数 | 由 EDTA 脱钙产生（第 1 节） |

旧机理先验（`data/mechanism_timeseries_quantiles.csv` 的 `whole_resistance_ratio`）正是按这一
**准静态纯电阻网络**逐层积分得到的；它只含 `phi(t,d)`，不含任何频率项，是第 3 节三个缺口的根源。

## 3. 原理三：串联电阻积分与归一化阻抗比

把颅骨沿厚度离散为 N 层，电极有效截面积 `A_cell`，每层厚 `dx_i`：

```
R    = sum_i dx_i / (sigma_i * A_cell)      (沿厚度串联积分，准静态纯电阻)
Z0   = Z(t=0)
R_Z  = Z(t) / Z0                            (归一化阻抗比)
```

按定义 `R_Z(t=0) ≡ 1`，这是所有模型必须满足的硬门槛（评价标准 B7）。归一化同时消掉
`A_cell`、电极几何与绝对电导标度，使不同鼠、不同批次可比。

**旧机理先验的三个结构性缺口**（数值由落盘数据自动渲染）：

| 缺口 | 机理侧证据 | 实测侧证据 | 后果 |
|---|---|---|---|
| **频率无关** | 先验 `R_Z_raw` 与 `f` 完全无关，只有剂量 × 时间一条曲线族 | 100 / 120 / 1000 / 10000 Hz 实测明显分层 | 机理方程缺频率维度，是最大误差源 |
| **脱钙动力学太慢 / 幅度太小** | t=95 min 先验 `R_Z_raw` 只降到 `0.794–0.849`（改性量约 0.15–0.21） | 实测条件均值降到 `0.119–0.924`（改性量 0.08–0.88） | 需要放大改性量或补时间维度 |
| **95 min 截断 + 尿素回升** | 先验在 95 min 取末值平台，无回升项 | t=105（乙醇+尿素）实测 `R_Z` 回升 | 所有单调模型无法表达 |

**结论**：偏差不是「参数没调好」，而是机理方程**缺频率维度、缺界面极化、脱钙动力学被过度平滑**。
A1 系列用经验协变量在外面补，A2 则把频率直接写回机理方程（第 4–5 节）。

## 4. 原理四：界面极化 / CPE 与并联导纳（本轮核心修复）

交流测量下颅骨不是纯电阻：骨基质 / 孔壁界面与电极-电解液界面存在**双电层电容**与
**Maxwell-Wagner 界面极化**，其频响常用**恒相位元件 CPE** 描述：

```
Y_CPE = Q * (j*omega)^n        0 < n < 1,  omega = 2*pi*f
```

CPE 导纳随频率**上升**（`n>0`）。因此真实颅骨的等效电路是
**离子通路 `G_ion(t,d)` 与界面极化旁路 `G_pol(f)` 并联**：

```
Y(f,t,d) = G_ion(t,d) + G_pol(f)          Z = 1 / Y
```

| 频段 | 主导支路 | 对脱钙 phi 变化 | 归一化结果 |
|---|---|---|---|
| **低频 100 / 120 Hz** | 离子通路 `G_ion` | 敏感：脱钙 → `sigma`↑ → `G_ion`↑ → `Z` 明显下降 | `R_Z` 下降显著 |
| **高频 1000 / 10000 Hz** | CPE 旁路 `G_pol(f)` | 不敏感：旁路分流占主导，phi 变化被分母稀释 | `R_Z` 更接近 1（系统性偏高） |

这正好解释实测「**同一时间下高频 `R_Z` 系统性偏高**」，而且**不需要任何经验 `ln(f)` 协变量**。
旧机理是「准静态纯电阻」，A2 是「频率内生的并联导纳」，这是两条机理路线最本质的差别。

## 5. 原理五：delta_eff 的完整推导与数学性质（TrackA2 方程）

### 5.1 从 `Y(0)/Y(t)` 到 `1/(1+delta_eff)`（逐步代数）

设基线离子导纳 `G0 = G_ion(0)`，脱钙带来的**相对增量**为
`delta(t,d) = A·(d/D0)^beta·(t/T0)^p`，界面极化旁路 `G_pol(f) = rho·(f/F0)^n`，则

```
G_ion(t,d) = G0 * (1 + delta(t,d))
Y(0)       = G0 + G_pol(f)
Y(t)       = G0 * (1 + delta) + G_pol(f)

R_Z = Y(0) / Y(t)
    = [G0 + G_pol] / [G0*(1+delta) + G_pol]
    = 1 / [1 + G0*delta / (G0 + G_pol)]
    = 1 / (1 + delta_eff)

delta_eff = G0 * delta(t,d) / (G0 + G_pol(f))        <-- 频率进入分子的可辨识组合
```

在**旁路主导**极限（`G_pol >> G0`，对应较高频 / 强界面极化）：

```
delta_eff ~ (G0/rho) * (f/F0)^(-n) * delta(t,d)
         = a0 * (d/D0)^beta * (t/T0)^p * (f/F0)^(-s)      a0 = (G0/rho)*A,  s = n
R_Z       = 1 / (1 + delta_eff)
```

> **澄清**：早期 121 行概览把 `G_pol(f) ~ (f/F0)^(-s)` 直接写成「CPE 频散」，那是对
> `delta_eff` 频率因子的**等效简写**。严格链条是：CPE 旁路导纳随 `f` **上升** → 分母
> `(G0 + G_pol)` 变大 → `delta_eff` 被稀释 → `delta_eff ∝ f^(-s)`。这也说明 `s` 只是
> CPE 指数 `n` 在旁路主导近似下的等效值（第 9 节 E9）。

### 5.2 三个参考标度（固定，不参与拟合）

| 标度 | 取值 | 作用 | 为什么这样取 |
|---|---|---|---|
| `D0` | 0.10 mol/L | 剂量归一化 | 取剂量的中间量级，使 `a0` 有明确参考条件 |
| `T0` | 100 min | 时间归一化 | 接近改性观察窗上限（95 min），使 `p` 落在易辨识区间 |
| `F0` | 100 Hz | 频率归一化 | 最低测量频率；`f/F0 ≥ 1`，`(f/F0)^(-s) ≤ 1` |

### 5.4 数学性质（可直接验证）

| 性质 | 推导 | 意义 |
|---|---|---|
| `R_Z(t=0) = 1` | `t=0` → `(t/T0)^p = 0` → `delta_eff = 0` → `R_Z = 1` | **基线天然自洽**，无需人为锚定（B7） |
| 值域 `(0, 1]` | `delta_eff ≥ 0` → `1/(1+delta_eff) ∈ (0,1]` | 无需 clip，不会越出物理范围 |
| `∂R_Z/∂t < 0` | `p > 0` → `delta_eff` 随 `t` 增 → `R_Z` 降 | 单调下降 |
| `∂R_Z/∂d < 0` | `beta > 0` → 剂量越高改性越强 | 剂量分层 |
| `∂R_Z/∂f > 0` | `s > 0` → `(f/F0)^(-s)` 随 `f` 减 → `delta_eff` 减 → `R_Z` 升 | **高频 `R_Z` 系统性偏高** |

**单调性是双刃剑**：它保证了基线自洽与物理合理性，但也使 A2（以及所有 A1 模型）
无法表达 t=105 尿素段的回升（E8）。

## 6. 原理六：参数可辨识性（为什么最终是 4 个参数）

### 6.1 尺度冗余的代数证明

由 `delta_eff = G0·delta / (G0 + G_pol)`：若把 `G0` 与 `rho`（从而 `G_pol`）同时乘以任意 `lambda > 0`，
分子分母同乘 `lambda`，`delta_eff` **不变**，`R_Z` 不变。因此**只有比值 `G0/rho` 可辨识**，
`G0` 与 `rho` 各自不可辨识 —— 这就是 6 参数形式里 `a0` 与 `rho` 双双顶到优化上界、互相补偿的原因。

## 7. 原理七：逐模型的机理成分溯源

### 7.1 A1.1 拉伸指数 —— 无机理成分

`R_Z = C + (1-C)·exp(-(b·t)^n)`，`b = b0 + b1·d + b2·ln(f/100)`。直接对时间拟合衰减曲线，
把剂量与频率塞进 `b` 的线性组合；`C` 是平台、`n` 是形状指数。
**完全脱离机理链路**，是唯一不含任何机理成分的模型（5 参数无物理量纲）。

### 7.2 A1.2 A+ —— 机理先验只作一个查表特征

`R_Z = a + b·R_Z_raw + c·t + d·ln(f/100)`。其中 `R_Z_raw` 来自
`data/mechanism_timeseries_quantiles.csv` 的 `whole_resistance_ratio` **q50**，
由 `run_three_routes.py` 的 `raw_prior()` 用 `np.interp` 把秒级曲线插值到 7 个全局时间点。
由于先验**频率无关、动力学太慢**（第 3 节），A+ 必须补 `c·t` 与 `d·ln(f/100)` 两个经验协变量 ——
**补 `ln(f)` 等于承认机理侧缺频散 / 界面极化项**，但这是经验层补丁，不是机理改进（E3）。
代价：`c` / `d` 无物理出处，t=0 外推偏离 1（落盘值 `0.929`），需人为锚定；model.py 需读外部 CSV，非自包含。

### 7.3 A1.3 H1 混合 —— 机理改性量作形状骨架

`R_Z = 1 - kappa·(f/100)^(-s)·(1-R_Z_raw) - eps·t`，用 `delta = 1 - R_Z_raw` 作形状骨架，
`lambda(f) = (f/100)^(-s)` 乘在 `delta` 上，`-eps·t` 补时间漂移。
`lambda(f)` 来自 CPE 一阶展开 `lambda(f) ≈ 1 - s·ln(f/f0)`，
故 `R_Z ≈ 1 - kappa·delta + kappa·s·ln(f/f0)·delta`，预言频率效应应是 **`ln(f)×delta` 交互项**。

> **一条机理预言被数据否定**（Mechanism Fusion 历史落盘）：实测加性 `c·ln(f)` 的 LORO 0.436
> 优于交互形式 0.428，说明 `lambda(f)` 的幂律只是**最简假说下的等效参数化**，
> `s` 不是被辨识的 CPE 指数（E9）。这也是 A2 把 `s` 明确标注为等效频散指数的原因。

### 7.4 A2 纯机理 —— 全部内生

第 2–5 节的全部链条（Archie → 脱钙 → CPE 并联导纳 → `delta_eff`）都在机理方程内部，
**频率 / 剂量 / 时间三个维度全部内生**，零经验回归系数、零外部数据依赖。
`TrackA2/model.py` 完全自包含，仅依赖 numpy。

### 7.5 A3 机理驱动经验 —— 机理定形状，经验只做保形校准

```
R_mech = TrackA2 的纯机理预测（前 4 个物理参数，stagewise 固定）
R_Z    = 1 - eta*(1 - R_mech) - eps*(t/105)
```

| 系数 | C1 拟合值 | 物理 / 校准含义 | 边界 |
|---|---|---|---|
| `eta` | 0.9626 | 缩放机理改性幅度；小于 1 说明纯机理略高估改性量 | [0, 3] 内 |
| `eps` | 0.0410 | 补机理尚未覆盖的时间漂移 | [-0.5, 0.5] 内 |

`eta=1, eps=0` 时**严格退化为 A2**（嵌套关系），因此经验层的边际贡献可直接量化：
四条件 LORO 相对 A2 提升约 +0.028 ~ +0.040（第 8 节）。
**诚实边界**：`eta` / `eps` 是拟合校准系数、不是物理常数；「机理驱动」指结构来自机理，
不指全部参数可溯源（E10）。

### 7.6 TrackB —— 机理 ensemble + conformal 校准

机理 **Latin Hypercube Sampling (LHS) ensemble** 对机理参数采样，产生
`sim_q05 / q50 / q95`；折 × 频率分层的 **conformal 校准**给出 padding：

```
p_(fold,f) = tolerance_f * q_f      q_f = Quantile_0.90(内层 cross-fit 分数)
calibrated_lower = clip(sim_q05 - p, 0, 1)
calibrated_upper = clip(sim_q95 + p, 0, 1)
```

- **B1 诊断**：最终区间宽度约 **97.09%** 来自 padding，基础 LHS 参数不确定性仅 **3.00%**。
  「区间过宽」的根因是 conformal padding 补偿「仿真 vs 实测」的系统性偏差，
  **不是 LHS 参数采样范围不足** —— 盲目扩大 LHS 采样没有用。
- **只报 coverage / width / Winkler，不报 R² / RMSE**；逐点覆盖率 ≠ 整条曲线联合覆盖；
  基线 t=0 与尿素 t=105 无校准区间；验证集 22/24 鼠；0.05 M 存在 role × 剂量混淆。
- 四条件指标是**既有 392 点 LOO 校准区间按条件切片的统计**，本轮未重新拟合、未重新校准。

## 9. 原理九：必须诚实说明的边界（完整版）

| 编号 | 边界 | 理由 | 对应评价标准 |
|---|---|---|---|
| M1 | **物理量是被标定，不是从第一性原理推导** | A2 的 `a0/beta/p/s` 由实测最小二乘标定，只有物理量纲与物理含义 | E10 |
| M2 | **`s` 是等效频散指数，不是被辨识的 CPE 指数** | 只有 4 个频率点；幂律 / 加性 `ln(f)` / 交互形式统计不可分；单一 `f^(-s)` 只在旁路主导极限成立，需独立宽频 EIS 介电谱实验 | E9 |
| M3 | **`(t/T0)^p` 是脱钙动力学的等效描述** | `p` 约 0.8 的次线性幂律反映扩散限制的整体趋势，不是被辨识的孔隙率演化方程；真正修复需用孔隙率 / 钙含量实测重标定 `phi(t)` | E10 |
| M4 | **`delta_eff` 单调 → 尿素 t=105 回升无法表达** | 所有 A1 / A2 / A3 模型皆然；需引入尿素导致的蛋白 / 孔道再封闭或界面重构项 | E8 |

| M6 | **TrackB 约 97% 宽度来自 padding** | 根因是「仿真 vs 实测」系统性偏差，不是 LHS 参数不确定性；另有逐点 ≠ 联合、22/24 鼠、role × 剂量混淆、上游机制选择非严格嵌套 | C6/C7 |
