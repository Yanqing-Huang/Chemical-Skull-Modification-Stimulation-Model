模型结构

SD 大鼠颅盖沿厚度方向分为三层：

  • 外板（密质骨）~0.43 mm
  • 板障（松质骨）~0.20 mm
  • 内板（密质骨）~0.17 mm

总厚度约 0.8 mm，参数推测自人体颅骨文献，标注为理论先验。

控制方程

多孔介质液相质量守恒：

∂(εc)/∂t = ∂(De ∂c/∂x)/∂x − ν kr c q
∂q/∂t = −kr c q
ε = ε₀ + α(q₀ − q)
De = Dbulk ε / τ

50% 乙酸仅外侧 Robin BC、内侧零通量；EDTA 和尿素完全浸没，内外表面均为 Robin BC。

三步时序改性

  1. 50% 乙酸预处理（300 s）——酸溶解初步脱钙
  2. EDTA 螯合（30 min，0.1 mol/L）——主脱钙阶段
  3. 饱和尿素（10 min）——溶胀，不消耗固相钙

漂洗后保留 q 和 ε，游离液相组分清零。

诊断量

Thiele 模数 φ = h √(kr q₀ / De)
有效因子 η = tanh(φ) / φ
Biot 数 Bi = kf h / De

φ≫1 内扩散控制；φ≪1 动力学控制；Bi≫1 液膜阻力可忽略。

电学模型

Archie 型电阻率：

σ = σm + σf εm

4–30 Hz SSVEP 频段采用准静态电导率近似（吴小明论文：低频段呈阻性）。

不能仅凭体积传导模型预测 PLV 或直接证明 SNR 提升。

参数来源边界

  • 吴小明论文：外板/内板为骨密质，板障为含骨髓与板障静脉的骨松质
  • 刘澳论文：外板–板障–内板三明治结构与分层网格思路
  • 林婧璇论文：三层厚度测量方法；人体数值不直接迁移给 SD 大鼠
  • 固定化 PPT 提供 De / Thiele / Biot 方法论
  • 所有 SD 大鼠参数标为推测先验；频率仅影响电学读出层
