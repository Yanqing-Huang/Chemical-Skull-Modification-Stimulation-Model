# TrackA3 — 机理驱动经验模型路线（本轮新建）

机理给函数形状与全部约束，经验层只加 2 个受约束的保形校准系数：

```
R_mech = TrackA2 的纯机理预测（前 4 个物理参数，stagewise 固定）
R_Z    = 1 - eta*(1 - R_mech) - eps*(t/105)
```

- `eta` 缩放机理幅度，`eps` 补机理未覆盖的时间漂移；`eta=1, eps=0` 时严格退化为 A2（**嵌套**）。
- t=0 天然=1；`model.py` 完全自包含，不读外部数据文件。
- 四条件 LORO 全部第一（0.520 / 0.733 / 0.641 / 0.768），是「拟合程度 + 可解释 + 可外推」
  综合最平衡的选择；相对 A2 的经验层边际贡献为 LORO +0.028~0.040。

诚实边界：eta/eps 是拟合校准系数、不是物理常数；「机理驱动」指结构来自机理，
不指全部参数可溯源。详见 `../docs/MECHANISM_PRINCIPLE.md`。

## 本模型涉及的机理原理

> 见 [`../docs/MECHANISM_PRINCIPLE.md`](../docs/MECHANISM_PRINCIPLE.md) 第 5、7.5、9 节。

- **机理骨架 100% 来自 TrackA2**：EDTA 脱钙 → Archie 电导 → CPE 并联导纳 →
  `R_mech = 1/(1+delta_eff)`；频率 / 剂量 / 时间三个维度全部内生，4 个物理参数 stagewise 固定。
- **经验层只做保形校准**：`eta` 缩放机理改性幅度（拟合值 0.9626，小于 1 → 纯机理略高估改性量）、
  `eps` 补机理未覆盖的时间漂移（0.0410）；二者均为拟合系数、**无物理量纲**。
- **嵌套可验证**：`eta=1, eps=0` 严格退化为 A2，故经验层边际贡献可直接量化
  （四条件 LORO 相对 A2 +0.028 ~ +0.040）。
- **诚实边界**：「机理驱动」指结构来自机理，不指全部参数可溯源（E10）；`delta_eff` 单调，
  尿素 t=105 回升无法表达（E8）；物理量由实测标定、非第一性原理推导（总纲 M1/M4/M5）。
