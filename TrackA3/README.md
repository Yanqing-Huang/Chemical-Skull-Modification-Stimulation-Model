# TrackA3 — 机理驱动经验模型路线（本轮新建）

机理给函数形状与全部约束，经验层只加 2 个受约束的保形校准系数：

```
R_mech = TrackA2 的纯机理预测（前 4 个物理参数，stagewise 固定）
R_Z    = 1 - eta*(1 - R_mech) - eps*(t/105)
```

- `eta` 缩放机理幅度，`eps` 补机理未覆盖的时间漂移；`eta=1, eps=0` 时严格退化为 A2（**嵌套**）。
- t=0 天然=1；`model.py` 完全自包含，不读外部数据文件。
- 四条件 LORO 全部第一（0.520 / 0.733 / 0.641 / 0.768），是「拟合程度 + 可解释 + 可外推」
  综合最平衡的选择；相对 A2 的经验层边际贡献为 LORO +0.028~0.040。

诚实边界：eta/eps 是拟合校准系数、不是物理常数；「机理驱动」指结构来自机理，
不指全部参数可溯源。详见 `../docs/MECHANISM_PRINCIPLE.md`。
